## Реализовано

- Отдельная папка `steam-showcase-sifu-preview-01/` с `index.html`, `styles.css`, `script.js` и тремя локальными PNG.
- Мобильная тёмная примерка профиля KentRAP с шапкой, областью Steam Artwork Showcase и дополнительной колонкой на широком экране.
- Фон SS_Landscape и аватар KentRAP взяты по тем же общедоступным внешним адресам Steam CDN, которые применялись в старых тестовых страницах.
- Переключение вкладок A/B/C без скачивания, отображение одного оригинального PNG прямо внутри макета.
- Отдельная действующая ссылка «Открыть оригинал» на каждый PNG (новая вкладка).
- Сохранение естественных пропорций изображений без обрезки и имитации финальных слотов Steam.
- Явная маркировка страницы как **тестовой**, а не production-экспорта для Steam.

- Введён фиксированный десктопный макет шириной 1200 CSS px с центральным профилем 912 px и видимыми полями фона SS_Landscape.
- Внутри профиля две колонки (648+12+252 px); правая остаётся видимой в мобильной примерке.

## Исправление фиксированной ширины витрины (2026-11-03)

Пользователь прислал скриншот Android: изображение выглядело как крупный обрезанный фрагмент, вместо полного горизонтального PNG в области мастерской. Ширина должна оставаться фиксированной, а высота — меняться с пропорциями выбранного PNG.

- Коммит `gh-pages`: [`5175a200de76bba5676342bbb90fc3403e524be4`](https://github.com/kentrap2011-hub/stopgame-ratings-data/commit/5175a200de76bba5676342bbb90fc3403e524be4).
- У контейнера `.workshop-preview` теперь строго `width/min-width/max-width:626px`; у исходного `img` фиксированная CSS-ширина **626 px** и `height:auto`, чтобы высота вычислялась по собственному aspect ratio исходника. Стиль ширины задан также inline как защита от устаревшего CSS.
- Из JS удалены записи `image.width=item.width` и `image.height=item.height`, которые меняли HTML-атрибуты размера и могли давать несовместимое отображение при загрузке HTML и CSS разных версий.
- Для `styles.css` и `script.js` добавлены новые query-версии `?v=workshop-fixed-width-02`, чтобы Android-браузер не использовал кэш предыдущей разметки.
- Переключение A/B/C, десктопная сцена, пять сегментов и фон не менялись. Все три оригинальных PNG имеют прежние SHA в GitHub.
- Проверены GitHub-diff и три Git SHA PNG. **Фактический рендер на Android после исправления — пока не подтверждён пользователем.**
