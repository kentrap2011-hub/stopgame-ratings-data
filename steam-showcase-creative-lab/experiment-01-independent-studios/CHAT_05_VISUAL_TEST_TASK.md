# Чат 5 — быстрый визуальный тест трёх финалистов

## Контекст
- Репозиторий: `kentrap2011-hub/stopgame-ratings-data`, источник истины: `main`.
- Обязательно полностью прочитай:
  - `steam-showcase-creative-lab/experiment-01-independent-studios/selection.md`
  - `steam-showcase-creative-lab/experiment-01-independent-studios/12-concepts.md` (для исходных описаний трёх выбранных)
- Не меняй критерии отбора и не придумывай новые концепции.

## Цель
Это **короткий пилот метода**, не производство итоговой Steam-витрины. Получить **ровно три сравнимых изображения-эскиза**, по одному на каждую выбранную концепцию:
1. Чат 1 №3 — «Последний сад».
2. Чат 2 №1 — «Шов».
3. Чат 3 №3 — «Типографика тишины».

## Правила честного сравнения
- У всех трёх одинаковая цель: один широкий **наглядный эскиз пятисекционной витрины**; пять секций воспринимаются как единая художественная работа, с видимыми промежутками между слотами. Не выдавай обычный постер, лишь разрезанный мысленно на пять частей.
- Общие ограничения: фон Steam SS_Landscape; палитра чёрная, графитовая, холодная тёмная; один сдержанный красный акцент; кино/нуар без неона и клише.
- Уровень усилий одинаковый: **по одной основной попытке изображения на концепцию**. Не делай множество тайных вариантов и не выбирай лучший только для одного финалиста. Если техническая ошибка, явно зафиксируй дополнительную попытку и причину.
- Придерживайся конкретных пятичастных композиций и критических деталей из `selection.md`. Не смешивай мотивы разных концепций.
- Изображение `KENTRAP` должно содержать правильные, читабельные буквы. При необходимости используй вектор/типографический композитинг, а не доверяй генерации букв без проверки.
- Геометрию реальных слотов не выдумывай: если удалось подтвердить размеры — используй их; иначе это **концептуальный эскиз**, а не готовый файл для загрузки в Steam.
- Не трать время на нарезку 15 финальных секций и полную техническую подготовку для Steam: это следующий этап только для победившего подхода.

## Выполнение
1. Сгенерируй **три отдельных изображения**; у каждого свой художественный язык, полная пятичастная композиция. Подписи с названиями концепций — только в тексте ответа, не поверх арта.
2. Покажи изображения пользователю прямо в чате, различимо пометь A «Последний сад», B «Шов», C «Типографика тишины».
3. Создай в GitHub на `main` файл `steam-showcase-creative-lab/experiment-01-independent-studios/visual-test-result.md` с перечнем A/B/C, фактически использованным подходом, количеством попыток, замеченными дефектами, статусом сохранения изображений, ссылками на них **только если они реально доступны**.
4. Если доступен реальный способ сохранить бинарные изображения в GitHub, сохрани их рядом под `renders/`, проверь доступность ссылок. **Не утверждай**, что изображения в GitHub, если это не подтверждено. Если загрузка файлов невозможна, сохрани минимум результат/описания/метаданные в `visual-test-result.md`, а изображения оставь непосредственно в чате и явно сообщи об ограничении.
5. Проверь, что markdown-файл результата читается из GitHub.

Ответ пользователю кратко: три изображения, ссылка на файл результата, фактический статус хранения изображений. Без просьб вручную переносить концепции из других чатов.
